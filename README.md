## 🎯 About The Project

A sleek and modern web-based Task Manager built to boost your productivity. This application allows you to seamlessly manage your daily tasks, categorize them for better organization, and track your progress in real-time.

### ✨ Key Features

- **Categorized Tasks:** Sort tasks into predefined categories like Personal, Work, Shopping, Coding, Health, Fitness, and more.
- **Dynamic Task Tracking:** Instantly see the number of active tasks per category.
- **Clean UI/UX:** A minimalist and highly intuitive interface with smooth animations and responsive design.
- **Interactive Checklists:** Easily mark tasks as completed or remove them entirely.
- **Client-Side Rendering:** Super fast operations using Vanilla JavaScript.
